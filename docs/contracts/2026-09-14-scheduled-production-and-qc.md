## Scope / acceptance

- Canonical Seedance helper accepts explicit regular scheduled cadences including
  30/60 minutes, preserves the 15-minute foreground boundary, and audits a fresh
  native snapshot against exact schedule/task/cadence without creating a timer.
- Current-board consistency audit compares the current scope, not equality with
  all historical provider rows; canonical status aliases are understood while
  conflicting aliases, duplicates and unobserved active claims remain flagged.
- Shared production guidance uses stable state-pointer automation prompts, not
  mutable job counts. Registration, actual execution and media/QC remain separate.
- Runtime QC template and a read-only coverage checker reuse source-hash-bound
  reviewed intervals and persist the exact next unresolved check in the existing
  per-asset report. Samples/native frames cannot satisfy playback/audio gates.
- Shared prompt review diagnoses reference leakage and spatial causality before
  another equivalent retry; changes an evidenced cause, not a negative wall.
- Test positive/negative cases, preserve unrelated dirty work, release through
  canonical preflight/apply/parity, isolated commit and GitHub sync.
- Apply the cadence correction and stable prompt to the already authorized
  existing automation only; preserve its task, cadence and notification policy.

## Non-goals

No new agent, schedule, browser owner, video generation, provider workaround,
automatic visual/audio judge, retroactive approval, or blanket drone rules for
other projects. Existing unrelated blocked harness goal stays intact. The checker
validates evidence structure and hashes, not whether a human/model actually saw
or heard what it reports. Repeated waiting without actionable work must close
with a disposition rather than manufacture more QC.
