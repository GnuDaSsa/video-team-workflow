# Native Aside prompting knowledge contract

## Goal
Make image/video wiki knowledge a bounded, traceable input to actual Astra authoring rather than an unverified pointer.

## Scope
- Audit actual native Aside and legacy knowledge consumption separately.
- Curate image/video creative knowledge from inspected official docs and current wiki sections, retaining source dates/confidence and excluding obsolete operations.
- Add a small deterministic selector (max six complete cards, 9,000 characters), current-source checks and author acknowledgement bound through request/receipt/provider payload.
- Keep English default, Astra author/current executor, reference/hash/mode/authorization gates. Music is explicitly outside the new image/video corpus.
- Update wiki canonical knowledge and native Aside skill, preserve original dirty Codex worktree.

## Acceptance
- New image/video request contains selected bounded content and provenance/hash, not just links.
- New author evidence must acknowledge the knowledge hash. Existing unscoped receipts remain read-only for historical audits, never retroactively rewritten.
- Catalog/source drift, unknown explicit tags, wrong stage/version, tampering, and missing acknowledgement fail closed.
- Unit tests, installed/source parity, wiki lint and real Astra author-only smoke test; no paid media or Generate.

## Limits
Selection, delivery and acknowledgement are observable. They do not prove internal reasoning, universal coverage, visual quality, or current UI/backend capabilities. Legacy routing/code and ongoing projects are not silently migrated.

## Verification closeout

- 444 native/deployer regression tests and 188 legacy tests pass; installed native source parity passes.
- Real gpt-6-astra direct authoring, not a mock: image selected four live-wiki cards / 1,992 characters; Seedance selected four / 2,197 characters. Both actual responses acknowledged the packet and both English payloads passed seal and submission verification. Same session execution was retained.
- Wiki lint: zero errors, 46 pre-existing raw hash warnings, 18 information notices. New source notes have matching body hashes.
- Configured full verification ends nonzero only at the existing Codex manifest plus five installed-file mismatches. No legacy operational source or production receipt was rewritten.
- No provider generation, browser input, visual quality/latency/cost gain or live REPL verifier-adapter success was claimed. Fastlane refuses a caller-made PASS object and holds without a real trusted adapter; existing CLI-verified direct input remains available.

## Audit findings

- Legacy routing is real: two existing selection/attestation records were inspected, including one ATTESTED case. The active catalog is under the local wiki, not the repository's wiki-extract folder.
- Two earlier native Astra author traces read prompt skills but had no direct wiki selection/read/knowledge receipt. Indirect skill distillation is not disproved; the finding is bounded to these traces and the native code path.
- An actual legacy packet included the always-selected hot-core Korean rule and always-selected Higgsfield community heuristics. New Aside excludes their operational defaults rather than copying the old router wholesale.
- The image skill mixes valuable composition/category knowledge with old Korean, Codex imagegen, API/AR and format constraints. New default author input is the reviewed packet, not that entire skill.
- Historical Claude ownership, an active-labeled append-only typography dataset, and a missing old typography numeric-token path are excluded from new automatic creative retrieval. Current composition, identity, edit-preservation, physics and typography principles remain useful.
- Forty-six older raw-file hashes fail the existing wiki lint. They were not silently rehashed or treated as newly validated evidence. New official-source research notes are separate immutable paraphrases.
