# Reference overlap counts scene duplication, not mandatory identity

## Evidence and scope
The user requested workflow corrections during a real two-block romance-anime cycle. Both adult characters need their approved identity sheets in each block; the old more-than-one shared image rule made that mandatory case impossible. Correct only the canonical Seedance shared contract and same-owner review fixtures. No reduction to identity attachment or verification, no new agent, no automatic image-test waiver.

## Acceptance
- Distinct scene decks sharing two required approved identity sheets pass the overlap review.
- Two reused scene references still require repair; a scene frame relabelled identity does not qualify.
- Removing a required character sheet remains blocked.
- Run configured quick verification and strict deployment parity; isolate commit and sync.
