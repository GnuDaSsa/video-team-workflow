# Music Video Production Team — merged into `videodirector`

**Use `videodirector` with MV mode.** Do not follow this file for rules; it no longer contains any.

MV and promo/contest work were maintained as two skills describing the same workflow in different words — 896 lines covering the same tool routing, character-sheet rules, QC standards and style memories twice over. Every correction had to be applied in both, and when it was not, they drifted. That drift is where contradictory instructions came from.

Everything here now lives in one place:

| What you came for | Where it is |
|---|---|
| Workflow, modes, tool routing, gates | `videodirector/SKILL.md` |
| MV-specific rules (music-first cutting, no stills in edit, one clip one use, no false microcutting, lyric/subtitle plan) | `videodirector/references/modes.md` → MV mode |
| Named role split (Music Director / Planner / Character Creator / Image Creator / I2V Producer), handoff formats, approval gates, project brief template | `videodirector/references/role-split.md` |
| Low-signal / hito-neko standing feedback | `videodirector/references/mv-team-standing-memory-low-signal-and-hito-neko.md` |

Roles remain available — they are responsibilities to walk in sequence, not agents to spawn.
