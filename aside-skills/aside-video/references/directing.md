# 장면 계획

- 최신 승인 brief에서 실제 등장 대상·인원·공간·참조 역할을 확정한다. 다른 컷의 인원 규칙이나 단일 피사체 예시를 전역값으로 옮기지 않는다.
- 시작 상태 → 원인/접촉 → 관찰 가능한 반응 → 끝 구도를 연결한다. 인물 전용/기체 전용 컷의 분리는 편집의 인과를 삭제하는 뜻이 아니다.
- 참조별 가져올 것/제외할 것/적용 장면을 정한다. identity·배경·의상 기준은 구도·첫 프레임·시간 순서와 별개다.
- 피사체와 카메라의 운동을 구별한다. 하나의 가능한 주 경로를 먼저 정하되 승인된 복합 액션을 편의상 삭제하지 않는다. 기체의 공중 질주는 자동차처럼 지면을 달리는 동작이 아니다. 깊이·스케일·기수 방향과 궤적, 교차 간격을 유지한다.
- 대상에 맞는 물리만 쓴다. 접지/체중, 관성, parallax, 재질 반응은 필요할 때만. 모든 장면에 머리카락·천·먼지·안개나 카메라 orbit를 붙이지 않는다.
- 같은 공간의 고정 지도와 컷별 카메라/몸 방향/시선을 구별한다. 역숏은 단순 좌우 반전이 아니다. 승인 identity·기체 구조·배경 원근을 유지한다.
- source 수·길이와 최종 편집 길이는 별개다. UI 기본값이나 과거 프로젝트 계획으로 현재 승인을 대체하지 않는다.
- 같은 실패가 두 번이면 강조어/금지어 추가를 멈추고 입력 → 공간 → 동작 → 효과 순으로 원인을 좁힌다. 수정 원인 하나를 Astra에 전달한다.

세부 이미지/영상 문법은 author_task의 지식 카드에 있다. 예시용 15초 댄스 타임라인이나 특정 look을 무관한 작업에 강제하지 않는다.
