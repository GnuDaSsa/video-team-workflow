# 경량 영상팀 연출·QC 기준

## 브리프를 영상으로 번역

- 한 클립에 하나의 읽히는 사건/퍼포먼스를 둔다. 보통 도입→변화→마무리의 3~4개 시간 구간이면 충분하다.
- 주인공의 신체/얼굴/의상과 공간·조명은 유지하고, 행동과 카메라는 분리해 서술한다.
- 카메라는 한 가지 물리적으로 가능한 경로를 우선한다. 전신 댄스에서는 발을 잘라 버리는 과도한 zoom/whip/orbit를 동시에 넣지 않는다.
- 장면의 실제 피사체에 맞는 현실적 반응만 설계한다: 사람의 체중 이동·옷의 지연, 물체의 관성·공간 parallax 등. 매 숏에 머리카락·소매·입자를 기계적으로 넣지 않는다. 인위적인 이펙트 나열로 동작 부재를 숨기지 않는다.
- 마지막 프레임은 안정된 착지·시선·pose로 끝낸다. freeze-frame 대신 살아 있는 호흡과 천의 settle을 남긴다.

## 실사

- 성인임이 명확한 독립 인물을 사용하고 특정 실존 인물의 얼굴/음성을 임의 복제하지 않는다.
- 실사는 피부결·고유 비대칭·실제 광원·노출·렌즈 거리로 설명한다. 플라스틱 피부, 과잉 모공, 과한 샤픈, CGI처럼 보이는 반사를 경계한다.
- 광원 위치와 그림자 방향을 일치시킨다. 모든 프로젝트에 네온/안개/역광을 자동 적용하지 않는다.
- 동작은 관절·접촉·원인→반응으로 쓴다. 순간 이동, 발 미끄러짐, 팔/다리 길이 변화, 인물 복제를 검수한다.

## 댄스 15초 단일 쇼트

- 성인 댄서 1명, 발까지 보이는 여유 있는 full-body 프레이밍.
- 예: 0~4초 리듬 진입/체중 이동, 4~10초 읽히는 footwork와 torso/arm accent, 10~14초 한 번의 controlled turn/마무리 phrase, 14~15초 안정된 최종 pose.
- 구체적인 박자/음악 스타일은 생성 목표이지 실제 정확성 보증이 아니다. 음악이 중요한 납품이면 실제 청취 및 sync 검증이 필요하다.
- 손은 읽히는 단순 형태, 무게는 지지 발로 이동, 회전은 발바닥 pivot과 몸통 관성으로 연결한다.
- 공중 묘기·옷 갈아입기·멀티 인물·잦은 카메라 cut을 동시에 추가하지 않는다. 기술적 과밀함보다 한 퍼포먼스의 완결성을 택한다.

## No-I2V

- 인물이 주인공이면 단발 영상이어도 필요한 캐릭터 기준을 먼저 준비한다. AI티가 나는 캐스팅은 단독 얼굴부터 다시 선정하고 시트를 파생한다. 0 reference는 identity 기준이 불필요한 장면 또는 사용자가 명시적으로 무참조를 선택한 경우만 쓴다.
- 반복 identity 또는 제공된 인물/제품이 있으면 해당 승인 reference를 실제 첨부한다. No-I2V가 identity 검증 생략을 뜻하지 않는다.
- 참조가 있으면 역할(얼굴/의상/공간/물체)을 분리한다. 첨부 순서는 시간 순서가 아니다.

## 범위·참조·반복 실패

- 실행자가 출력에 실제 등장하는 entity/인원/공간/시작→원인·접촉→반응→끝 상태를 계획하고 Astra에 전달한다. human_only/drone_only 같은 분리는 표현 대상의 분리이지 최종 편집의 인과 삭제가 아니다.
- 각 reference의 가져올 것/가져오지 않을 것/적용 장면을 명시한다. 배경은 배경, identity는 얼굴·체형·의상, motion은 동선·리듬이다. 파일명/업로드 지시는 model-facing prompt에 넣지 않는다.
- 카메라를 `추적 또는 정면`처럼 미결정으로 두지 않는다. 사용자가 승인한 인과적인 복합 카메라·액션은 짧게 만들려고 지우지 않는다.
- 같은 실패가 두 번 이어지면 강조어/금지어만 추가하는 재시도를 중단하고 입력→공간→동작→효과 순으로 원인을 찾는다. 문구 수정만 Astra가 하며 실물 QC와 입력 판단은 현재 세션이 한다.
- 원본 source 길이와 최종 편집 길이를 별도로 적는다. 15초 final이 15초 source 하나를 뜻하지 않는다. 승인된 source 수·길이를 UI 기본값이나 옛 프로젝트 컷 수로 대체하지 않는다.
- 기존 작업의 명시 언어 override, 실제 발화 원문, 최신 승인 배경·identity와 HOLD를 읽고 유지한다. 특정 프로젝트의 영어/한국어 지시나 Luna owner를 신규 제작 전역값으로 복사하지 않는다. 오래된 state보다 새 상태가 있다는 이유만으로 새 Generate 권한을 추정하지 않는다.
