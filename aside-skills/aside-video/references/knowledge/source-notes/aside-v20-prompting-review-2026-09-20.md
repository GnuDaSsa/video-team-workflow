Runway Seedance 2.0 review: Reference inputs are role-scoped scene ingredients, not automatically ordered shots or enforced first/last frames. Describe the intended scene and each input contribution with clear outcome-focused wording. Its Reference, Start/End and text-only modes are distinct. Documentation of available modes is not permission to leave an existing project mode. Provider moderation failures require a compliant changed input, not repeated identical resubmission.
