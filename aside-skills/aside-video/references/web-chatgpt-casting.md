# 웹 이미지 실행

1. author-executor.md의 검증 payload를 준비한다. 기존 ChatGPT 탭을 attach하거나 없으면 https://chatgpt.com/ 에서 현재 UI를 확인한다. 접근 실패 시 HOLD하며 API/imagegen으로 자동 대체하지 않는다.
2. 필요한 실제 참조를 첨부하고 payload.prompt를 관측한 composer에 그대로 입력한다. 이미지 생성/편집을 명시한다. fill 오류 뒤에는 먼저 수용된 원문을 읽고, 내용이 같으면 중복 입력/전송하지 않는다.
3. 생성 중 preview를 최종으로 승인하지 않는다. 완료 결과의 원본을 다운로드해 실제 파일과 요청한 변경/보존 범위를 검사한다. 후속 편집은 승인 원본을 실제 입력으로 쓰며 기억에만 의존하지 않는다.
4. requested_product=ChatGPT Images 2.5, observed_product=실제 UI 표기를 구별한다. 미노출 backend_variant는 unverified다. API 모델명/품질 옵션이나 추론 강도를 웹 backend 확인으로 쓰지 않는다.

## 인물일 때만

- 이미 승인된 identity가 있으면 재사용한다. 새 얼굴이 필요하거나 기존 캐스팅을 거절했을 때만 단독 얼굴 후보부터 선정한다. 거절된 시트는 다시 쓰지 않는다.
- 실제 활동·체형·기억나는 얼굴 구조·표정으로 캐스팅한다. 미용 광고형 완벽함이나 과장한 모공/비대칭을 자연스러움으로 착각하지 않는다.
- 승인 얼굴을 실제 참조로 전신·후면·필요한 시트를 파생한다. identity와 의상 앞뒤를 유지하고, 영상 prompt에서 각 패널은 얼굴/체형/의상 기준일 뿐 구도·배경·첫 프레임이 아님을 명시한다.
- No-I2V도 필요한 인물 시트는 유지한다. 제품·드론·풍경에는 얼굴→전신→시트 절차를 적용하지 않는다. 불필요한 후보 배치나 스트레스 테스트 수량을 추가하지 않는다.

웹 편집은 지정하지 않은 픽셀까지 바꿀 수 있다. identity·손발·참조 패널·배경·문자와 변경되지 않아야 할 영역을 실제 결과로 검사한다. 모델 우위·장기 identity·전체 기능 지원을 한 번의 성공으로 주장하지 않는다. 세부 창작 원칙은 이미 author_task에 포함된 지식 카드로 처리한다.
